# Guess Correct Finger

Guessing game where you try to guess how many fingers the computer is showing. After submitting your guess, the computer reveals its randomly generated answer.

Yes, computers don't have fingers!

## Live Demo : [Play Guess Correct Finger](http://amalk.au/guess-correct-finger-game/)

## Features

- Randomly generated finger count (0–5).

- Simple user input and guess submission.

- Instant feedback indicating whether your guess is correct.

- Displays the computer's randomly generated answer.

## Tech Stack

- HTML5

- CSS3

- Vanilla JavaScript

## Getting Started

No installation or dependencies are required.

Clone the repository:

```
git clone https://github.com/amalk-au/guess-correct-finger-game.git

cd guess-correct-finger-game
```

Open `index.html` directly in your browser.

Alternatively, start a local development server:

```
python3 -m http.server 8000
```

Visit:

```
http://localhost:8000
```
